# Stroke Prediction & Risk Factor Analysis 🧠🔬

## Project Overview
This data science project focuses on analyzing healthcare data to identify key risk factors contributing to strokes and predicting their occurrence. By leveraging exploratory data analysis (EDA) and visualization tools, the project aims to uncover insights within patient health indicators (such as age, hypertension, heart disease, and average glucose level).

## Tools & Libraries Used
- **Language:** Python
- **Environment:** Google Colab
- **Libraries:** - `Pandas` (Data manipulation and cleaning)
  - `Matplotlib` & `Seaborn` (Data visualization and statistical plotting)

## How to View the Project
You can view the full analysis directly in GitHub by opening the `.ipynb` file above, or click the **Open in Colab** badge inside the notebook to run the code interactively.
